# 常见问题

### 打开时提示「无法验证开发者」/「Apple 无法检查其是否包含恶意软件」/「已损坏」

本项目没有付费的苹果开发者签名，第一次打开要手动放行一次：

- **macOS 15 及以上**：「右键 → 打开」已经不管用了。先双击一次（提示后点「完成」），然后打开「系统设置 → 隐私与安全性」，拉到最下面的「安全性」，在「已阻止使用 CrossPet」旁边点「仍要打开」，输入开机密码，再点「打开」。
- **macOS 13、14**：在「应用程序」里右键点 CrossPet →「打开」→「打开」。
- **任何版本都可以**：在终端运行一次
  ```bash
  xattr -dr com.apple.quarantine /Applications/CrossPet.app
  ```
  （如果你放在别的位置，把路径换成实际位置。）

用 README 里「方式一」的一条命令安装，或者从源码 `./install.sh` 装的，都不会遇到这个问题。

### 桌宠不跟着 AI 动

1. 先看接入情况：`python3 tools/integrate.py status`
2. 让 AI 干点活，然后看状态文件有没有更新：
   ```bash
   ls -l /tmp/crosspet/
   cat /tmp/crosspet/claude-state.json
   ```
   - **文件没出现或时间不更新**：AI 那边的钩子 / 插件没在运行。
     - Claude Code：需要**新开**会话才会读到新钩子。
     - Codex：新钩子要在 Codex 里审查并「信任」（`/hooks`）才会运行。
     - DeepSeek Harness：改完要 ⌘Q 完全退出再打开。
     - Antigravity：改完要重开；需要 2.0 以上版本。配置格式写错时它会整份忽略，看 `~/Library/Logs/Antigravity/language_server.log` 里有没有 `Failed to parse hooks file`。
   - **文件在更新但桌宠没变**：确认桌宠当前显示的是对应角色（切到那个 AI 的 App，或右键「换成 …」）。
3. 钩子脚本报错可以手动试一条：
   ```bash
   echo '{"hook_event_name":"Stop"}' | python3 "$HOME/Library/Application Support/CrossPet/crosspet-hook.py" claude
   ```

### 用 CC Switch 切换服务商后，她不跟着 Claude 动了

CC Switch **3.x** 切换服务商时会把整个 `~/.claude/settings.json` 换成它的模板，CrossPet 的增强版 mod / 钩子（还有你自己的状态栏、别的 mod 之类）会被一起冲掉。

- **CrossPet 会自动接回去**：桌宠开着时发现被冲掉了，几秒内自动接回去，并在气泡里说一声；新开的 Claude 会话生效。只补 CrossPet 自己的那一项，不动别的；在 CrossPet 里撤销过的不会再接。
- **根本解决：把 CC Switch 升级到 4.0 以上**。4.0 起切换只换地址、密钥、模型这几个关键字段，别的配置原样保留。
- 还在用 3.x 又想保住自己的其他设置：把它们写进 CC Switch 的「通用配置」，切换时会合并进去。

另外，在 Claude Code 里走 DeepSeek、智谱的兼容接口时，她会换成大肥鱼、GLM 来演。

### 额度 / 余额显示「被别的工具改掉了」

`python3 tools/integrate.py status` 里 Claude Code mod 显示这一行，说明 mod 文件还在、但 `settings.json` 里加载它的那一项被别的程序删了（见上一条）。桌宠开着时会自动接回去；也可以手动重新接入一次。

### 为什么状态写在 /tmp

有的 AI 运行钩子时有沙箱（比如 DeepSeek Harness），只允许写 `/tmp`。`/tmp` 重启后会清空，没关系，下次 AI 干活会重新写。

### 额度 / 余额不显示

- **Claude**：只有增强版 mod 能拿到额度，标准钩子不行。增强版 mod 需要终端里的 Claude Code 2.1.287 以上（桌面 App 2.1.286 以上），装了不显示的话看 [接入教程](接入教程.md) 里的「装了不起作用？」。
- **GPT**：要在右键 →「设置…」里打开「显示 GPT 额度」。桌宠会让电脑上的 Codex 自己去查实时额度（Codex 桌面版或命令行装了、登录了就行），用了重置卡、在别的设备上用过都能跟上（Codex 干活时最多 1 分钟、闲着时最多 2 分钟）。额度后面带「· 15:30 的数据」这样的时间，说明这次没问到（断网之类），显示的是那个时候的数。一直不显示的话，看「设置…」里这个开关下面写的原因（没找到 Codex、没登录……）。在 Windows 上用 WSL 里的 Codex 的，WSL 开着时会去 WSL 里问。
- **Gemini**：要在右键 →「设置…」里打开「显示 Gemini 额度」，而且 Antigravity 要开着。Antigravity 关掉后额度会消失，重新打开一分钟内会回来。
- **DeepSeek**：要先在 DeepSeek Harness 里配置好 API Key，插件每 10 分钟查一次，刚装好最多等 10 分钟。

### 会不会读我的对话 / 密钥

- 钩子只拿到「哪个事件、哪个工具」，只写状态，不保存任何对话内容。
- GPT 额度（默认关）：让 Codex 自己查用量（不对话、不耗额度），CrossPet 只拿额度数字。
- Gemini 额度（默认关）：只向本机的 Antigravity 后台服务问额度，用的是它只在本机有效的临时令牌。
- DeepSeek 余额：插件通过 DeepSeek Harness 官方凭据接口取 Key，只用来调官方余额接口，不写盘、不上传别处。
- CrossPet 本身只会联网做一件事：每 3 小时（以及电脑从睡眠中醒来时）查一次 GitHub 上有没有新版本（只读公开的版本号，不发送任何数据）。

### 什么都没输入，她就开始干活 / 一下子手忙脚乱

Codex 桌面版首页的「主动建议」会在后台开临时对话，翻你最近的文件（接了 Gmail、日历的话还会翻邮件和日程）来写建议卡片，一打开 Codex、或者隔一阵就跑一次。1.3.2 之前她会把这当成你在干活；1.3.2 起只跟着你自己开的对话（有会话记录的）动，这种后台对话不演。

不是 Codex 的话，右键「反馈问题…」，选「AI 干活时她没反应」和是哪个 AI，发一份过来：附带的事件记录能看出这个 AI 发来了哪些消息、每条是演了还是被跳过了。

### 切到 AI 的 App 后，角色过了半秒才换

这是故意的：App 启动时窗口会短暂地抢焦点、让焦点，立即响应会让角色来回闪，所以要在那个 App 上停留半秒才换。

### 她一直浮在最上面，挡住东西了

右键 →「显示层级」：
- **跟着 AI**：正在用 AI 的 App、AI 等你回答、或者刚干完活时浮在最上层（AI 在后台干活时不浮上来，不挡你干别的），其他时候是普通窗口，会被别的窗口挡住
- **普通窗口**：从不置顶
- **始终在最上层**：一直浮在所有窗口上面（默认）

另外，全屏看视频、演示、玩游戏时她会自动隐藏（「设置…」里的「全屏时隐藏」可以关掉）。临时不想看到她，按 ⌃⌥P（Windows 是 Ctrl+Alt+P）藏起来，再按一次叫回来。也可以直接把她拖到不碍事的地方，位置会记住。

### 我退出了她，怎么又自己出来了 / 怎么不自己出来

接入的 AI 开始干活时（新会话、发消息；DeepSeek Harness 是一打开），她没开着就会自己打开。
- 从右键菜单「退出」后，在那之前就开着的 AI 不会再把她叫回来；重新打开 AI、或者重启电脑后恢复
- 光打开 AI 的软件、还没开始对话时不会出现（这时候 AI 还没通知桌宠）；WorkBuddy 要等发第一条消息
- 不想要这个功能：「设置…」→ 关掉「AI 开始工作时自动出现」
- 排查：每次检查的结果写在状态目录的 `autostart.txt`（macOS：`/tmp/crosspet/autostart.txt`；Windows：`%LOCALAPPDATA%\CrossPet\state\autostart.txt`）

### macOS 菜单栏里找不到爪印图标

菜单栏右边图标太多时（尤其是带刘海的 MacBook），macOS 会把放不下的图标藏起来。按住 ⌘ 把不常用的图标拖出菜单栏腾出位置，或者按住 ⌘ 拖动调整顺序；CrossPet 会记住爪印图标的位置。

### 深色背景上她身后有一圈亮光

那是背景光晕。1.2.1 起默认「自动」：系统是深色模式时不显示。系统是浅色、但你常用的窗口是深色的话，右键 →「设置…」→「背景光晕」选「关闭」；反过来想一直显示就选「始终显示」。

### 更新命令在「3/3 接入 AI」报 `unbound variable`

这是 2026-10-06 之前的安装脚本的问题（macOS 自带的 bash 3.2 把紧跟在变量后的中文当成了变量名），已经修好。再运行一次同样的安装命令就行，App 和接入都会更新好。

### 能在 Windows / Linux 用吗

暂时不行，悬浮窗用的是 macOS 原生接口。画面部分是网页（`app/web/`），欢迎移植。
