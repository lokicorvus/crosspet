# 红温：甩她、炸毛、哄好（42 张）

甩她（按住快速来回拖），红温值一档档上去：不耐烦 → 鼓脸 → 红温；红温后她别过身去不理你；这时摸她就是哄，摸几下消气、害羞地原谅你。被甩时还会晕。
蒸汽、发红、发抖是 App 用代码画的，图里**只画脸红**，不画蒸汽和符号。

每个文件全文复制发给 GPT，附件附上文件开头写的参考图。画好放到 `characters/<角色>/raw/`，文件名用清单里的。

| 姿态 | 什么时候 |
|---|---|
| `annoyed` | 红温值第一档：不耐烦 |
| `puffed` | 第二档：鼓脸 |
| `redhot` | 第三档：红温（满脸通红、握拳跺脚） |
| `sulk` | 红温后别过身去赌气 |
| `dizzy` | 被甩晕 |
| `coaxed` | 红温时摸她：嘴上还气，眼神软了 |
| `forgiven` | 哄好了，害羞地原谅你 |
