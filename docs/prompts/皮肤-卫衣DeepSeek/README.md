# 皮肤：穿 Claude 卫衣的 DeepSeek（约 38 张）

DeepSeek 的另一套衣服：奶白色拉链卫衣、胸前挂着「Claude」名牌、橙色星号发卡，没有女仆头饰。设计参考来自小红书用户（小红书号 5149587399）的卫衣 DeepSeek 设定图——**放进仓库发布前请先取得作者同意，并在 README 致谢里注明出处**。

做好后在「设置…」里给 DeepSeek 换皮肤（女仆装 / 卫衣），用的是同一套台词和动作逻辑，只换立绘。
