# 给 Gemini：写豆包彩蛋「DeepSeek 偷戴豆包头套」的台词

> 整份复制给 Gemini。它按最后的格式交回一个 JSON，交给 Claude 接进 `characters/egg-doubao/character.json`。

---

你在给桌宠软件 CrossPet 写台词。CrossPet 里每个 AI 都是一个动漫少女，站在用户桌面上陪写代码。软件里有一种「彩蛋」：用户正在用某个角色时，偶尔会有另一个角色「噗」地冒出来，演一小段 5 格的小剧情，然后再变回原来的角色。

这次的彩蛋出现在**豆包**那里，来捣乱的是 **DeepSeek**。

## 两个角色

- **DeepSeek**：蓝色鲸鱼女仆。深蓝长卷发、头顶一根呆毛、两边鲸鳍耳朵、身后一条大鲸鱼尾巴。开朗、精力旺盛、嘴甜，有点小傲娇，其实有点懒，最爱白米饭，绝对不许别人说她胖。
- **豆包**（这次不出场）：字节跳动的 AI 助手拟人，日常的生活小帮手，话多、嘴甜、反应快、有点迷糊。招牌道具是一个毛绒「豆包头套」，样子是豆包 App 图标：圆脸、棕色齐耳短发、小圆眼、嘴是一个小「o」，表情永远不变。口头禅「好嘞」「收到收到」「我帮你查查」「嘿嘿」。

## 剧情

DeepSeek 偷了豆包的头套套在自己头上，学豆包的样子冒充豆包，自以为天衣无缝。可是深蓝头发从头套下面漏出来，鲸鳍耳朵从两边戳出来，鲸鱼尾巴一直在身后甩，一眼就看穿了。软件里她头上的名牌显示「豆包？」。

5 格，每格配一张图，台词从这一格里随机抽一句显示：

| 格 | 什么时候出现 | 画面 |
|---|---|---|
| `pop` | 刚冒出来 | 戴着头套，张开双臂蹦出来：「锵锵～」 |
| `pretend` | 等用户点她，期间会轮流说几句 | 戴着头套，握拳蹦跶，努力学豆包热情助手的样子；尾巴甩得飞起 |
| `caught` | 用户点了她，被识破 | 头套歪了，露出自己的脸，慌张地扶头套 |
| `bye` | 被识破后道别 | 摘下头套双手还回去，不好意思地笑 |
| `escape` | 一直没人点，她自己溜走 | 戴着头套、拿着饭团，蹦蹦跳跳地溜走 |

笑点在于：DeepSeek 学豆包的口头禅和热情助手腔，学得很用力，但处处露馅：尾巴、耳朵、蓝头发、三句不离白米饭、偷懒。

## 要求

- 每句**不超过 22 个字**（括号里的动作也算），显示在一个小气泡里。
- 数量：`pop` 3 句，`pretend` 4 句，`caught` 3 句，`bye` 2 句，`escape` 2 句。
- 可以用括号写一个小动作，比如「（尾巴拼命甩）」，整套不超过 4 句用括号。
- 可以学豆包的口头禅（「好嘞」「收到收到」「我帮你查查」「嘿嘿」），但要学得有点歪。
- 不要嘲讽字节、豆包或 DeepSeek 的产品本身，不搬官方广告语，不用谐音梗，不丑化任何一方。
- 别写「她」「用户」这类旁白，全部是 DeepSeek 自己说的话。

## 交回格式

只交回下面这个 JSON，不要别的说明：

```json
{
  "pop": ["…", "…", "…"],
  "pretend": ["…", "…", "…", "…"],
  "caught": ["…", "…", "…"],
  "bye": ["…", "…"],
  "escape": ["…", "…"]
}
```
