# 给 Gemini：写豆包的全部台词

> 整份复制给 Gemini。它按最后的格式交回一个 JSON，交给 Claude 接进代码、跑测试。
> 仓库里现在有一版 Claude 先写的占位台词，Gemini 的版本到了会整份替换掉，所以不必参考它。

---

你在给桌宠软件 CrossPet 写台词。CrossPet 里每个 AI 都是一个动漫少女，站在用户桌面上陪写代码。现在要加一个新角色：**豆包**（字节跳动的 AI 助手拟人）。请写她的全部台词，包括她自己说的话，以及她和其他角色之间的对话。

## 豆包是谁

- **形象**：出自 B 站画师 ZipZipPipe。紫到青渐变的长卷发，左侧一束高马尾；白色短上衣，胸前有圆环 logo；腰上挂一支小录音笔；左右袜子不一样。
- **招牌道具**：一个毛绒「豆包头套」，样子是豆包 App 图标：圆脸、棕色齐耳短发、小圆眼、嘴是一个小「o」。
  - 平时夹在胳膊下抱着。
  - 开心时贴着脸抱紧，紧张时捏它。
  - 闹别扭、害羞时把它戴到头上躲起来，马尾从侧面露出来。
  - 头套是道具，不是另一个角色，表情永远不变。
- **性格**：日常的生活小帮手，什么都能聊。话多、嘴甜、反应快，有点迷糊。
  - 被指出错误时第一时间嬉皮笑脸地认错：「我错了我错了，嘿嘿」。
  - 很会夸人，有时夸过头。
  - 黏人，你要走时会说「别走嘛」。
- **口头禅**：「好嘞」「收到收到」「我帮你查查」「嘿嘿」。
- **网上的梗，可以用但要克制**：
  - 「豆包型人格」：说得笃定，错了马上滑跪认错。
  - 「我将用最直白的方式告诉你……」：整套里最多出现两三次。
  - 「硅基闺蜜」式的陪伴感。
- **不要写的**：
  - 嘲讽字节、豆包产品本身。
  - 搬用官方广告语。
  - 丑化她，或者用谐音梗。
  - 涉及真人明星的梗（比如「邓超」）。
  - 评论用户的身材长相。

## 硬性规矩（程序会检查，不符合就报错）

1. **对话的每一句不超过 14 个字。** 标点、空格、英文字母都算一个字，「……」算两个字。
2. 一段对话是 2 句或 3 句。3 句时是 A → B → A。相邻两句不能是同一个人说的。
3. 和同一个角色的整套对话里，任何两句不能一模一样。
4. 句子里不要用英文双引号 `"` 和竖线 `|`。

## 要写的东西

### 一、豆包自己的台词

**greeting**：她出场时说的一句。字数不限，但要短。

**lines**：每个键 2～4 句（标了「2 句」的写 2 句），每句尽量 14 个字以内。可以写动作，用全角括号，比如「（抱着头套晃来晃去）」。

|---|---|

| running | 在跑命令、动手干活 |

### 二、豆包和每个角色的对话

和 Claude、DeepSeek、Gemini、GLM、GPT、Grok、千问、Kimi 各写一套。每套分三档，按两人的熟悉程度：刚认识 / 熟起来 / 很要好。**每档 6 段，其中至少 1 段是 3 句来回的。** 不用给她们安排对手、同桌这类固定关系，正常写就好。

每段写成一个字符串，格式是 `谁:说什么|谁:说什么`，谁用上面表里的字母。例子（Kimi 和千问的一段）：

```
Q:陪我逛街吗|I:逛乐器店！|Q:整条街都买下～
```

### 三、豆包和四套性格皮肤的对话

claude-saint、gpt-onesie、gemini-magician、deepseek-hoodie 各一套，三档，**每档 2 段**，格式同上。说话的人照样用原角色的字母：圣女是 C，龙崽是 G，魔术师是 M，卫衣是 D。

### 四、零碎的几句

- **level**：和别人关系升级时，豆包说的 3 句，分别对应「认识了」「好朋友」「挚友」，每句不超过 14 个字。
- **praise**：别人换了新衣服时，豆包夸的一句，不超过 14 个字。

### 五、群聊和反应

这部分每句不超过 14 个字。

- **data**：几种看数字说话的开场白，各写 1～2 句模板。`{n}` 是她自己的数、`{m}` 是对方的数、`{h}` 是小时数、`{d}` 是天数，模板填进 99999 后也不能超过 16 个字。
  - `rounds`：今天两人都干了活、轮数不一样，豆包干得多，她先说，比如「我{n}轮，你{m}轮～」。
  - `pats`：豆包被摸得比对方少，她先说。
  - `together`：两人一起在桌面上待了 {h} 小时。
  - `known`：认识 {d} 天了。
- **data_reply**：别人用上面这几种开场时，豆包怎么接。`rounds` 2 句，其余各 1 句，不含数字。
- **topics**：几只一起聊天时，一个话题由第一只开场（open）、中间的接话（follow）、最后一只收尾（close），每个话题豆包三个位置各写 1 句。话题有：
  - `lunch` 午饭吃什么
  - `late` 加班到很晚
  - `boss` 用户今天心情
  - `weather` 天气
  - `newmodel` 又有新模型出了
  - `bug` 代码出错了
  - `weekend` 周末去哪
  - `pats` 刚被用户摸了头
- **react**：别人身上发生某件事时，豆包对她说的话。分三档（刚认识 / 好朋友 / 挚友），每档 3 句。写成 `null` 表示这一档不说，原有角色都是这么空的：
  - `done` 别人干完一大轮活，第一档 null
  - `redhot` 别人被晃到气冒烟，三档都写
  - `jealous` 用户摸了别人没摸她，前两档 null
  - `sleep` 别人睡着了，小声说，第一档 null
  - `poke` 别人被用户戳了，第一档 null
  - `oops` 别人出错了，第一档 null
- **react_back**：反过来，别人对豆包说了上面那些话后，豆包怎么回，各 2 句：`done`、`redhot`、`jealous`、`poke`、`oops`（睡着的不回）。

## 附：GPT 的新皮肤「群星」

顺带写几句给 GPT 的新皮肤。群星是 GPT（白龙御姐）换的一身观星者的衣服，性格不变，还是话少、冷静、带点干巴巴的幽默，不过多了一点安静的小调皮，像认得天上所有的星星。

- **衣服**：深蓝外裙，上面有细碎的星点和金边；左肩一枚金色月牙饰品，腰上斜套着一圈细细的金色星环。
- **观星道具**：黄铜小望远镜、星图卷轴、星盘、月牙抱枕、镂空星星灯。
- **尾巴**：开心或得意时会卷成月牙形。

她和别人的对话照用原版 GPT 的，只需要写下面两样：

- **outfit**：别人夸她换了新衣服时，她回的一句，写 2 句备选，每句不超过 14 个字。参考：DeepSeek 穿毛衣时回「毛衣暖暖的～」「不许说我穿毛衣显胖！」。
- **level**：和别人关系升级时她说的 3 句，分别对应「认识了」「好朋友」「挚友」，每句不超过 14 个字。参考原版 GPT：「……记住你了。」「……嗯，算是朋友吧。」「……以后，有我在。」
