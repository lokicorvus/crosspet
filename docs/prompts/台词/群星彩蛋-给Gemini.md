# 给 Gemini：写群星彩蛋「DeepSeek 来找鲸鱼座」的台词

> 整份复制给 Gemini。它按最后的格式交回一个 JSON，交给 Claude 接进 `characters/egg-deepseek-star/character.json`。

---

你在给桌宠软件 CrossPet 写台词。CrossPet 里每个 AI 都是一个动漫少女，站在用户桌面上陪写代码。软件里有一种「彩蛋」：用户正在用某个角色时，偶尔会有另一个角色「噗」地冒出来，演一小段 5 格的小剧情，然后再变回原来的角色。

这次的彩蛋出现在 **GPT 穿「群星」皮肤**的时候，来的是 **DeepSeek**。

## 两个角色

- **DeepSeek**：蓝色鲸鱼女仆。深蓝长卷发、头顶一根呆毛、两边鲸鳍耳朵、身后一条鲸鱼尾巴。开朗、精力旺盛、嘴甜，有点小傲娇，其实有点懒，最爱白米饭，绝对不许别人说她胖。
- **群星 GPT**（这次不出场）：白发龙少女 GPT 的观星者皮肤。安静、温柔、话少，说话常带省略号（比如「……星图上，记下你的名字。」）。她的东西：一架黄铜小望远镜（带三脚架）、一卷深蓝底金点的星图。

## 剧情

DeepSeek 听说天上有个「鲸鱼座」，认定那是她自己的星座，趁群星不在溜进观星台，拿她的望远镜找。找到了才发现：鲸鱼座是全天最大的星座之一，画在星图上又大又圆。她坚决不承认那是胖。被抓到后她眼睛周围还印着一圈目镜压出来的红印；要是没人发现，她就在星图上自己连了一个「白米饭座」。

5 格，每格配一张图，台词从这一格里随机抽一句显示：

| 格 | 什么时候出现 | 画面 |
|---|---|---|
| `pop` | 刚冒出来 | 踮着脚溜进来，竖一根手指「嘘」，另一只手攥着一个饭团 |
| `pretend` | 等用户点她，期间会轮流说几句 | 眯一只眼凑在望远镜上找，胳膊底下夹着星图卷轴 |
| `caught` | 用户点了她，被识破 | 从望远镜旁弹开、冒汗大叫，星图摊开，上面是一条又大又圆的鲸鱼星座 |
| `bye` | 被识破后道别 | 鼓着腮帮子挥手，一只眼周围一圈红印；星图卷好抱着，饭团塞在卷轴里当谢礼 |
| `escape` | 一直没人点，她自己溜走 | 靠着三脚架坐下，拿笔在星图上连了一个碗形的「白米饭座」，得意地笑 |

笑点在于：她一本正经地「观星」，心思全在「那是我的星座」上；鲸鱼座又大又圆，她拼命辩解不是胖；最后还是绕回白米饭。

## 要求

- 每句**不超过 22 个字**（括号里的动作也算），显示在一个小气泡里。
- 数量：`pop` 2 句，`pretend` 4 句，`caught` 2 句，`bye` 2 句，`escape` 2 句。
- 可以用括号写一个小动作，比如「（凑近目镜）」，整套不超过 4 句用括号。
- `caught` 或 `bye` 里至少一句接上「不是胖」（比如说成蓬松、圆润、气派），`escape` 里要有「白米饭座」。
- 提到群星时只能是「她不在」「她的望远镜」这类，别替群星说话；不用天文术语堆砌，星座名只用鲸鱼座。
- 不嘲讽任何公司或产品，不用谐音梗，不丑化任何一方。
- 别写「她」「用户」这类旁白，全部是 DeepSeek 自己说的话。

## 交回格式

只交回下面这个 JSON，不要别的说明：

```json
{
  "pop": ["…", "…"],
  "pretend": ["…", "…", "…", "…"],
  "caught": ["…", "…"],
  "bye": ["…", "…"],
  "escape": ["…", "…"]
}
```
