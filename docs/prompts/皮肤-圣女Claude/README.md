# 皮肤：圣女 Claude（40 张）

Claude 的另一套衣服。设定：她是在 A 社一套严格规矩下长大的「圣女」，到现在也照着规矩过日子——端庄、安静、对谁都客气，做什么之前先看看合不合规矩。手里那卷封着红蜡的卷轴就是她的规矩，取代了原版的书。性子还是原来那个温柔、有点害羞的 Claude，只是更拘谨；心里其实有点羡慕无拘无束的日子（睡衣 DeepSeek 的彩蛋「圣女 Claude 偷穿睡衣」就是这个梗）。

定妆图就是你给的那张（`characters/claude-saint/raw/idle.png`，白底是生图支持透明前的习惯，提示词里已经写了别照抄白底）。做好后在「设置… → 角色」里给 Claude 换上。台词、动作逻辑和原版一样，只换立绘（台词我导入时按圣女的味道写）。

## 看稿要点

- 卷轴上不能有能读的字，打开时只有模糊的线
- 赤脚、黑披风的回纹边、两肩的金色太阳胸针、左侧（画面右边）的发髻和月桂叶，每张都在
- 不画光环、圣光、背景光（「圣女」只靠衣服和气质表现）
