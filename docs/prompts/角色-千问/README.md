# 角色：千问（Qwen）

**设定来源：形象出自 B 站 ZipZipPipe**（CrossPet 按其设定重新绘制，性格和专属动作是 CrossPet 的二创）。上线时 README 致谢和 `characters/LICENSE.md` 的来源表都要写上。

**性格（loki 10-19 定）**：阿里家**温柔大方的千金**。有钱、大方、爱请客，觉得把好东西分给大家是理所当然的；说话温柔有礼，不傲娇、不刻薄；对钱有点「不太在意」的天真。
和其他角色的位置：Claude 安静爱书、GPT 冷静御姐、DeepSeek 勤快（其实有点懒）的女仆、GLM 心机涨价狐——千问是**被宠大的千金**，和 GLM「涨价」正好相反。

**表现情绪主要靠扇子**：笑时掩嘴、思考时点下巴、害羞时遮脸、展开扇子表示得意、生气时「啪」地合上。手提包只在个别动作里出现（待机、道别、傍晚、送礼）。
