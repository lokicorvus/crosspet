# macOS 性能模式

右键桌宠或菜单栏爪印，菜单首项显示当前运行模式，也可直接切换。设置页顶部显示「省电 / 均衡 / 完整」三个按钮和当前选中项。选项保存到 macOS 偏好，重启后保留。未配置时仍使用完整模式。

| 行为 | 省电 | 均衡 | 完整（默认） |
| --- | --- | --- | --- |
| 人物 / 光晕持续 CSS 动画 | 关闭 | 一个 100 ms 时钟推进 | 原有浏览器动画时钟 |
| SVG 特效 | 关闭 | 保留，随同一个时钟推进 | 原有 SVG 时钟 |
| 图片 | 按需加载 | 按需加载 | 预加载全部角色姿态 |
| 读取工作状态 | 1 秒 | 0.5 秒 | 0.3 秒 |
| 鼠标位置检查 | 0.2 秒 | 0.1 秒 | 0.05 秒 |
| 点击区域缓存 | 1 秒 | 0.5 秒 | 0.25 秒 |
| 自动闲置动作尝试 | 关闭 | 至少间隔 60 秒 | 每 20 秒 |
| 同姿态换图 | 关闭 | 20 秒 | 8 秒 |
| 眨眼间隔 | 20–30 秒 | 8–14 秒 | 3–6.5 秒 |

工作事件、姿态图片、气泡、点击、拖动和手动彩蛋继续可用。均衡模式只控制持续动画，短暂的淡入、点击动作等仍采用原有过渡，故 10 Hz 不是整个窗口的严格帧率上限。页面隐藏时停止均衡模式的绘制时钟；恢复可见后重新建立一个时钟。切换模式会清理旧绘制时钟和原生轮询计时器。

未重新编码或缩小角色图片。按需加载改变的是加载时机；首次遇到未缓存姿态时可能多一次图片加载。切到完整模式后预加载的缓存不会因再次切到省电模式而立即释放，重启后的内存表现也可能不同。

另有默认关闭的[应用生命周期绑定](macOS应用绑定.md)，可以指定一个桌面应用，最后一个实例退出后桌宠也退出。它复用此处状态轮询，不新增监控进程。

该设置只由 macOS 宿主提供。共用网页没有收到该设置时保持完整模式；旧宿主的设置页面会隐藏这行。Windows WebView2 与 Intel 真机尚未实测。

## 初步测量

设备：Mac mini（Mac16,10），Apple M4，10 核 CPU（4 性能核 + 6 能效核），16 GB 内存；macOS 27.0.1（26A434），arm64，WebKit 22625.1.29.11.28。

使用独立的 WKWebView 测试窗口，每个模式 / 姿态均启动新进程，窗口可见、260 × 362 点，GPT 角色，光晕开启、开发者姿态固定，无额度查询或网络请求。每组预热 5 秒，再采样 20 秒；文件和系统缓存未清空，系统其他应用负载未固定。完整模式是本分支的完整模式，未另测上游旧二进制。

| 姿态 | 模式 | 合计平均 CPU | 末尾内存足迹 |
| --- | --- | ---: | ---: |
| idle | 完整 | 18.39% | 138.74 MiB |
| idle | 均衡 | 5.00% | 113.39 MiB |
| idle | 省电 | 0.20% | 57.32 MiB |
| reading | 完整 | 28.42% | 142.35 MiB |
| reading | 均衡 | 7.14% | 119.47 MiB |
| reading | 省电 | 0.10% | 59.02 MiB |

CPU 按测试主进程及三个 WebKit 辅助进程的 CPU 时间增量除以经过时间求和，100% 相当于占满一个 CPU 核，不是整台 10 核机器的百分比。内存采用 macOS footprint 工具的物理内存足迹，非 RSS，且只在采样末尾测一次。辅助进程按启动前后新增进程识别；GPU 和 Networking 通过测试 bundle 缓存路径核对，新增的唯一 WebContent 按进程类型和启动时段配对。

这六组结果只说明这台机器上两种固定姿态的短时表现。尚未做充分重复或统计分析，也未测电池功耗、峰值、长时运行、真实连续事件、悬停、拖动或频繁换角色，也不包含生产 App 原生轮询与钩子开销。不能视作固定降幅或占用上限。

## 本机验证与复现

```sh
app/build.sh
python3 tests/native_performance_test.py
swiftc -parse-as-library -module-cache-path build/module-cache tests/WebRenderingTests.swift -o build/web-rendering-tests -framework Cocoa -framework WebKit
build/web-rendering-tests "$PWD"
python3 tests/performance_bench.py
python3 -m unittest discover -s tests -p 'integrate_test.py'
```

这些 macOS 图形测试需在有桌面会话的机器执行；Linux 云环境无法替代 WebKit 和原生窗口验证。构建含 arm64 / x86_64；本机只验证 arm64 运行。

原生测试检查偏好、菜单勾选、爪印提示及反复切换时的定时器替换。WebKit 测试检查本地图片、工作事件、气泡和点击，确认均衡 CSS/SVG 时间仍在推进、隐藏时停绘制时钟、完整模式恢复动画、反复切换不叠加计时器，以及设置的可见性和旧宿主兼容性。测试预览和原始资源采样输出写入忽略的 `build/`。

先前本地渲染测试与本次复测的 CPU 有明显波动，可能与系统调度、缓存和其他应用负载有关；未逐项归因，因此不以短时样本承诺固定降幅。公开测量摘要已去掉 PID、设备序列号与个人路径。
