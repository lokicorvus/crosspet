# 久坐提醒、喝水提醒

## 为什么做

用户提的需求：在电脑前一坐几个小时，忘了起来、忘了喝水，希望桌宠到点提醒一下。
这是给所有用户的功能，所以默认关、能在设置里调，不想要的人完全感觉不到它。

## 要做到的

- 设置页「通用」里加两行：**久坐提醒**、**喝水提醒**。每行一个开关 + 一个间隔下拉（30 / 45 / 60 / 90 / 120 分钟）。
  默认：开关都关；久坐 45 分钟，喝水 60 分钟。
- 到点了，主桌宠演一下、说一句，**30 秒**后自己恢复，不用点。这 30 秒里点她照常是摸头，提醒同时收起。
  - 久坐：伸懒腰（`stretch`，所有角色都有），台词如「坐好久啦，起来走走～」。
  - 喝水：开心（`happy`），台词如「喝口水吧～」。以后画了 `drink` 姿态就换上：代码里用 `drink` 这个姿态名，`POSE_FALLBACK.drink = 'happy'`。
- 通用台词写在 `LOCAL_LINES`（键 `remindSit`、`remindWater`，各几句）；角色在 character.json 的 `lines` 里写了同名键就用角色的（现有 `linesOf` 规则）。

## 怎么算时间（只按时间，不看键鼠、不看 AI 会话）

- **久坐**：从开启（或 App 启动、或上次提醒）起算，满间隔就到点。
  页面被藏起来 / 屏幕睡着（外壳已经会调 `setPageHidden`）连续超过 5 分钟，算你起来过，久坐计时从重新出现那一刻清零。
- **喝水**：从开启（或 App 启动、或上次提醒）起算，满间隔就到点。藏起来不清零，藏着的时候不提醒，出来后再说。
- 改间隔：从改的那一刻重新算。关了再开：从开的那一刻算。
- 计时只在内存里，App 重启从头算（重启本身说明人动过，这样也不会一开机就提醒）。

## 什么时候不说

- **夜里 23:00–7:00** 不提醒；到点落在夜里就跳过，计时从 7:00 之后的那一刻重新开始（夜里不攒）。
- 她正在忙（AI 干活姿态、多会话、彩蛋、更新中、开发者控制台、告别、正在换角色、贴边缩着）就先等；
  每分钟再看一次，**最多等 10 分钟**，还不空就跳过这一次，从现在重新计时。
  「闲着」沿用 Codex 重置提醒的判断：姿态是 idle / tired / sleeping，不在彩蛋里，`aiActivity() !== 'work'`。睡着时会叫醒她说。
- 久坐和喝水同时到点：只说久坐，喝水往后推 5 分钟。
- **只有主桌宠提醒**（`role === 'main'`），额外那几只不提醒，外壳也不把这个设置发给它们。

## 不做的

- 不读键盘鼠标空闲时间（用户选了只按时间算）。
- 不要求点一下确认「喝了 / 起来了」。
- 不和小本子联动（只记「提醒过几次」没意义；以后有点一下确认再说）。
- 不做可配置的勿扰时段，夜里时段写死。
- 不画新图（以后要画 `drink` 走 art/ 生产线，用户自己挑）。

## 做法

考虑过两种：
1. **判断逻辑单独一个文件 `app/web/break-reminders.js`（选这个）**：纯函数，输入「现在几点、上次什么时候、开关和间隔、她忙不忙、藏了多久」，输出「这一分钟说不说、说哪个、计时怎么变」。和 `codex-resets.js`、`peak-hours.js` 一样，网页和测试共用，夜里、等待、同时到点这些边界都能单独测。
2. 全写进 `index.html`：改动少一个文件，但计时规则没法单测，不选。

接线：
- `index.html`：引入新文件；`setBreakReminders({ sit, sitEvery, water, waterEvery })` 由外壳调；每分钟 tick 一次调纯函数，要说就 `show(pose, true)` + `say(line)`，30 秒后 `setPose(restPose()); say('')`（用 `revertTimer`，被别的事打断就跟着打断）；`setPageHidden` 记下藏起来的时刻。
- `settings.html`：两行开关 + 下拉；下拉改了发 `{cmd:'set', key:'sitEvery'|'waterEvery', value: 数字}`。
- macOS 外壳（`App+Integrations.swift` 的 set 分支、`pushSettings`、`App+Update.swift` 的初始化那串 js）：存 `sitRemind`/`sitEvery`/`waterRemind`/`waterEvery`，调 `setBreakReminders(...)`。
- Windows 外壳（`Pet.Integrations.cs` 的 set 分支和设置推送、`Pet.cs` 初始化那串）：同上。这台 Mac 上只能写，跑不了 Windows。
- 测试：`tests/break_reminders.test.js`（纯函数）；`tests/settings_multi_pets_test.cjs` 或新的 cjs 页面测试覆盖设置页两行的显示和发送。
- `CHANGELOG.md` 写一条；「新功能」页如有对应条目机制一并加。
