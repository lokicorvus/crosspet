# 角色页卡片墙（选角色、选衣服）· 设计

日期：2026-10-20　状态：方向 loki 已口头确认，待审阅本文；放 1.3.8 做（loki 定）
来源：角色和皮肤越来越多，右键「换角色」展开的名单一长串，要翻半天才找到（loki）

## 为什么做

现在换角色、换衣服靠右键菜单里的「换角色」子菜单。每套衣服各占一行（「DeepSeek · 女仆装」「DeepSeek · Claude 卫衣」……），已经十几行，以后还会更多。loki 想要游戏选人界面那样的体验：每个角色、每套衣服各有一张大立绘，看着图点选。和角色有关的设置也集中到同一页。

## 目标

- 设置的「角色」页改成卡片墙（loki 从三种方案里选了 A「卡片墙」，并要求衣服在上、角色在下）
- 每个角色、每套衣服各有一张新画的展示立绘（loki 定：新画，不用现有待机图）
- 右键菜单的「换角色」保留，点它直接打开设置的角色页，不再展开名单（loki 定）
- Mac 和 Windows 一起做

不做：
- 「召唤彩蛋」不搬，留在右键菜单里（loki 定）
- 不改换角色的规则本身：跟随前台 AI、跟随工作事件、每个角色记住上次穿的衣服，这些照旧

反目标（做出来但算失败的样子）：
- 还没画展示图的角色（用户自己加的角色、以后新加的皮肤）显示成空卡片或破图
- 设置窗口里点卡片后，桌宠没换或换错衣服
- 卡片墙在角色多了以后挤成一团、名字看不清

## 一、角色页从上到下

1. **当前角色的衣服**：一排大卡片，每套衣服一张，显示展示立绘和衣服名（原版显示 `outfit` 名，比如「女仆装」；没有 `outfit` 的显示「原版」）。点一张，桌宠马上穿上。正在穿的那张有高亮框。只有一套衣服的角色，这一排只有一张卡。
2. **她自己的设置**（只对当前这个角色）：
   - 名字（现有的「名字 / 保存」，搬到这里）
   - 有峰谷规则的角色（`peak-hours.js` 的 `RULES` 里有的，现在是 DeepSeek、GLM）且有别的衣服：「高峰穿 / 空闲穿」两个下拉。从「额度」页搬过来，只显示当前角色那一组（我的决定）。额度页不再保留这一项
   - 放在衣服下面（我的决定）
3. **所有角色**：一排小卡片，每个角色一张（彩蛋角色不出现，皮肤不单独占卡片）。卡片显示这个角色**原版**的展示立绘和名字；有几套衣服的在右上角标数字。点卡片：桌宠马上换成她，**穿原版**（loki 定），上面那排同时换成她的衣服。当前角色的卡片有高亮框。「穿原版」就是把她记住的衣服也改成原版（之后跟随前台 AI 切回她时也是原版），直接用现有的 `{cmd:'skin', id, skin:''}`；她已经是当前角色、正穿着别的衣服时点她的卡，同样换回原版（都是我的决定：点角色卡 = 选这个角色的原版，规则只有一条）
4. **通用开关**：跟随前台 AI 应用、跟随 AI 工作事件、随机彩蛋，原样放在最下面（我的决定）

卡片底色用角色的 `accent` 主题色做浅色渐变（展示图是透明背景，底色由程序画）。

## 二、展示立绘

- 每个角色文件夹里一张 `portrait.webp`（皮肤文件夹里也各一张）。生图提示词：`docs/prompts/展示立绘/README.md`，竖版 2:3、透明背景、全身、10 张统一构图
- 导入：从 `raw/portrait.png` 生成，裁掉空白后缩放到统一高度（具体高度留给实现，够设置页大卡片在 2 倍屏上清楚就行）。不走贴边 / 眨眼那些处理
- **没有 `portrait.webp` 的**（用户自己加的角色、还没画的皮肤）：用她的 `idle` 立绘代替，卡片照常显示
- `portrait` 不是姿态：不进 `poses`，桌宠本身不会用到它。两个外壳扫立绘时会把文件夹里所有 webp 当姿态（Mac `App+Characters.swift`、Windows `Store.cs`），要把 `portrait.webp` 排除掉
- `docs/自定义角色.md` 补一句：可以放一张 `portrait.webp` 当设置页的卡片图，不放就用待机图

## 三、右键菜单

- 「换角色」保留在原来的位置，不再有子菜单；点了打开设置窗口并切到「角色」页（设置已经开着就切过去、拿到前台）
- 只有一个角色时，和现在一样不显示这一项
- Windows 的右键菜单同样改

## 四、程序分工

- `settings.html`：角色页改版。现在外壳已经把 `characters`（含每个角色的 `skins`）、`character`、当前衣服交给设置页；另外需要每个角色 / 每套衣服的卡片图地址和 `accent`
- 换角色：沿用现有消息。点角色卡 = 换角色并穿原版（现有的 `{cmd:'skin', id, skin:''}` 或先换角色再换衣服，看哪个能一步到位，实现时定）；点衣服卡 = `{cmd:'skin', id, skin}`
- 设置页打开时要能跳到「角色」页（「新功能」卡片已经有按页跳转的机制，可以复用）
- 两个外壳：右键「换角色」改成打开设置角色页；设置页的角色数据里加卡片图地址
- 卡片图的地址：设置页要能加载到角色文件夹里的图（Mac 在 App 包里或用户角色目录，Windows 在数据目录），具体怎么给（文件地址、虚拟主机映射、data URL）留给实现，跟现有设置页能看到的资源方式保持一致

## 五、测试

- 设置页逻辑能抽成纯函数的（卡片列表怎么排、哪张高亮、没有展示图时退回待机图）写 node 测试
- Mac 实测：点角色卡、点衣服卡、右键「换角色」打开到角色页、用户自定义角色没有展示图时的样子、峰谷换装下拉只在 DeepSeek / GLM 出现
- Windows 由 Codex 跑一轮

## 留给实现的

- 设置窗口要不要加宽、卡片具体尺寸、一行放几张
- 角色很多时小卡片一行放不下：换行还是横向滚动
- 展示图导入后的统一高度

## 2026-10-28 更新：改成独立的换角色窗口

1.3.8-beta.2 在 Windows 上测，设置页 560 宽里的卡片太小（衣服卡约 117×156、角色卡约 70×92），100% 缩放下立绘看着糊；按卡片大小预先缩图（portrait-card.webp）后好一些，但图太小本身就看不清。loki 定：

- 换角色做成和反馈一样的独立窗口（`web/characters.html`，默认 760×740，可拖大小、记住大小），右键「换角色…」和设置「角色」页的按钮打开。和设置页同一条通道、同一份状态（外壳 pushSettings 两个窗口都推）。
- 左上大立绘（约 224×336，用 portrait.webp 512×768），右边只放角色名、衣服名、改名、峰谷换装，**不放介绍文字**（loki 定：就图片）。下面衣服卡、角色卡，比设置页里大。
- 鼠标停在卡片上时大立绘先预览那一套（角色卡预览她的原版），移开恢复；点卡片照旧马上换上。
- 设置「角色」页只留跟随前台、跟随事件、随机彩蛋三个开关和打开窗口的按钮。
- 展示图两种尺寸由 `tools/cards.py` 从 raw 原图生成：portrait 512×768（大立绘）、portrait-card 256×384（卡片），avatar 192×192。
