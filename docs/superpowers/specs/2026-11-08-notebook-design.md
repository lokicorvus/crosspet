# 她的小本子：你和她的相处记录（设计）

> 2026-11-08。来由：PR #46（@OvCherryBlossomRain）做了 Windows 悬停展开的角色主题菜单，七个角色各一套样式，但菜单项和右键菜单完全一样、只有 Windows、和「让开」都靠鼠标停在她身上。
> loki 定：不要悬停，把这个主题面板改成**你和她的相处记录**。主题样式沿用 #46 的思路（署名感谢）。

## 一、用户看到的

- 右键她 →「我们的小本子」（主桌宠、副桌宠都有；Mac、Windows 一样）。
- 她旁边弹出一个小面板，样式按她的人设（定稿原型：`build/notebook-preview.html`，不入库）：

  | 角色 | 本子 | 字体（标题/批注） | 人设细节 |
  |---|---|---|---|
  | Claude | 随身手册：皮面、横线纸、红页边、铜包角、书签丝带 | 霞鹜文楷 | 墨水瓶羽毛笔；铅笔批注、落款「今天也加油」 |
  | DeepSeek | 潮汐日志：浅海、光线、上浮气泡、青海波 | 站酷快乐体 | 女仆蕾丝花边+蝴蝶结；数字是三个气泡；「咕噜咕噜～」 |
  | GPT | 冰晶匣：切角、冰面反光、雪花 | 站酷小薇 | 话少：「……嗯。」「改好了再叫你。」 |
  | Gemini | 星夜：星空、月亮、星座 | 站酷庆科黄油体 | 面板顶上两只猫耳、猫爪印；「再摸摸喵」 |
  | GLM | 狐狸掌柜的流水账：红格账本、双红框 | 马善政毛笔 | 算盘、铃铛、铜钱；「这个值多少呢」「已入账」 |
  | Grok | 毒舌批改本：黑色点格纸、胶带 | 龙藏（红笔批注） | 「已阅·一般」印章、红圈、红波浪线、「阅 · Grok」 |
  | 千问 | 扇底春风录：宣纸、折扇、印章 | 志莽行书 | 「有点意思呢」「一笔一笔，写漂亮些」 |

  - 七张内容顺序一样（标题 → 三个大数字 → 细节 → 最好的朋友 → 小成就 → 合计），头部同高；变化只在材质、边框、数字块形状、插画和字体上。
  - 正文和数字用系统字体；角色字体只用在标题、分隔标题、批注、落款。字体随包打包（都是 OFL），按常用字子集化。
  - 批注 / 落款是她的台词：放 `character.json`（`notebook.notes`），交给美术对话写；没写的不显示。
  - 只画几何类插画（纹样、器物、光效）；动物、人物这类具体形象不手画，要用就请美术对话出透明底图。
  - 衣服沿用所属角色的样式，认不出的角色用 Claude 的手册。
- 面板记的是**你和她**的事；最下面一行小字是全部角色合起来的。
- 点面板外面、按 Esc、拖她、她走了 / 换角色 / 藏起来：面板收起。
- 打开时她就是平常的样子，不换立绘（#46 换图要替换页面核心的 `showImage`，不做）。

## 二、记什么

只记数字和日期，不记对话内容，只存在本机。

**起点 = 装 CrossPet 那天**（数据目录的建立时间）。新版装上之前的部分能补的就补（见第二节之二），补不回来的从新版开始记。

| 一栏 | 内容 | 怎么算 |
|---|---|---|
| 相处 | 第一次见面、认识第几天、在桌面上的累计时长 | 她当主桌宠或站着当副桌宠、窗口没藏起来、屏幕没睡：每分钟记一分钟（和友谊的「一起在场」同一个时钟） |
| 干活 | 陪你干了多少轮、累计干活时长、最忙的一天（几轮）、最长的一次 | 一轮 = 她的 AI 一次「开始干活 → 干完（Stop 一类事件）」；按角色算，不按客户端 |
| 互动 | 摸头、戳一下、被甩生气的次数；换过几次衣服、最常穿哪套 | 页面里本来就有这几个时刻 |
| 最好的朋友 | 她和谁心最多（几颗心、什么关系） | 读 1.3.9 的友谊记录，以前攒的也算；还没有一起站过的就不显示这一栏 |
| 小成就 / 纪念日 | 达成过的里程碑，最近一个在最上面 | 见第三节 |
| 底下一行 | 和大家一起多少天、一共多少轮 | 所有角色合起来 |

## 二之二、补算以前的记录

第一次打开小本子时在后台补算一次，算完存进记录，以后只靠 CrossPet 自己记。

| 一栏 | 来源 | 说明 |
|---|---|---|
| 干活（轮数、时长、最忙一天、最长一次、通宵） | 各 AI 程序在本机的对话记录：Claude Code `~/.claude/projects/**/*.jsonl`、Codex `~/.codex/sessions/**`、其他能找到的同理 | 只读每轮开始 / 结束时间和模型名，不读内容；按模型名算到角色（Claude Code 接 DeepSeek / GLM 等时算给对应角色）；只算装 CrossPet 之后的 |
| 认识日期 | 数据目录建立时间；每个角色第一次出现看 `switches.jsonl` | |
| 最好的朋友 | `friendship.json`（1.3.9 起） | 本来就在记 |
| 摸头 / 戳 / 生气、在桌面上的时长、换衣服 | 以前没存 | 从新版开始记 |

- 补算的部分在面板里标一行小字：「含装 CrossPet 之后、新版之前从 AI 程序记录里补算的部分」。
- 网页版 / 手机 App 的对话在云端，补不了；Claude Code 默认会删 30 天前的记录，能找到多少算多少。
- 小彩蛋：装 CrossPet 之前的轮数不计入，单独一行「认识你之前，你已经和她干了 N 轮」（没有就不显示）。

## 三、小成就 / 纪念日

- 第一批：认识 7 / 30 / 100 / 365 天；第 1 / 100 / 1000 轮活；一天 50 轮；凌晨 0–5 点还在陪你干活（「通宵」）；摸头 100 次；第一次有最好的朋友（第一次升到某个关系）。
- 达成时她说一句（只说一次），面板里留下日期。
- 台词放在 `character.json` 的 `milestones` 里，每个角色一套；没写的用通用台词。台词和角色性格有关，交给美术对话写（他们可以改 character.json 里的台词）。

## 四、存在哪、谁来记

- 由**主桌宠页面**记（它看得到所有角色的状态和摸头，友谊也是在这里记的），存 `localStorage['crosspet-notebook']`，外壳在数据目录另存一份 `notebook.json`，坏了 / 丢了从另一份恢复，规则同 `friendship.json`。
- 新文件 `app/web/notebook.js`：纯函数（记一次事件、按分钟累计、算里程碑、出面板数据），测试 `tests/notebook.test.js`。
- 每个角色一份：`{ firstMet, minutes, rounds, workMs, busiestDay: {date, rounds}, longestMs, pats, pokes, angry, skins: {皮肤: 次数}, milestones: {id: 日期} }`，外加按天的轮数（只留最近 60 天，用来算「最忙的一天」）。

## 五、面板窗口

- 面板是一个网页 `app/web/notebook.html` + 主题样式 `notebook-themes.css`，两边外壳各开一个小窗口，放在她旁边（按屏幕可用区域摆，和 #46 的 HoverMenuLayout 一样的思路）。
- 外壳只管开关窗口、摆位置；内容由主桌宠页面算好（`notebookFor(角色)`）交给面板。
