# 小本子和桌宠互动：性格不同的皮肤用自己的文字

> 2026-11-16。来由：loki 看了小本子文案，降智龙崽、DeepSeek（Claude 卫衣）这类性格和原版不一样的皮肤，不能和原皮共用同一套文字。

## 要什么、为什么

穿着性格不同的皮肤时，小本子里她写的、朋友写给她的、她和别人聊的，都要是这套皮肤的口吻。现在几乎都按原角色挑，打开降智龙崽的本子看到的是原版 GPT 冷冰冰的批注，Claude 卫衣看到的是原版 DeepSeek 的「饭钱挣够了」，对不上她平时的台词。

## 范围

- **要写的四套**（loki 定）：`gpt-onesie`（降智龙崽）、`deepseek-hoodie`（Claude 卫衣）、`claude-saint`（圣女）、`gemini-magician`（魔术师）。
- **不写**：`deepseek-pajamas`、`deepseek-winter`、`deepseek-knit`。主要是换衣服，性格还是 DeepSeek，照旧用原版。
- 不做：别人自己做的皮肤在自己的 `character.json` 里给本子写文字（做法 B，以后有需要再补入口）。

## 做法（loki 选 A）

| 做法 | 好处 | 代价 |
|---|---|---|
| **A. 皮肤文字和原版放在同一批网页文件里，按皮肤 id 单列，没写的退回原角色**（选这个） | 两个平台共用，Mac、Windows 外壳都不用改；测试能直接查四套写齐了；小本子字体从这几个文件抽字，新字自动收进去；`pair-chat.js` 的 `SKIN_PAIRS` 已经是这个做法 | 用户自己做的皮肤没法给本子写文字 |
| B. 写进皮肤的 `character.json`，外壳读角色时合并 | 用户自己做皮肤也能写 | 两个外壳都要改；文字散在各个皮肤文件夹，测试和抽字要另外读；第二页是两两互写，放 JSON 很长 |

## 怎么挑

- 谁穿着什么，用页面里现成的 `manifest.characters[id].skin`（主桌宠和额外那只都有）。
- 每张表先按「皮肤 id」找，找不到这一项（这一档、这一对、这一种）再退回原角色 id；原角色也没有就照旧走 `'*'`。
- 第二页留言按两边各自穿的挑：本子主人穿皮肤，换的是她的回复和本子上她自己的字；写留言的朋友穿皮肤，换的是那位朋友的留言。
- 已经记进小本子的「最近聊了什么」照原样显示，不按现在穿的改写。

## 每套要写的

| 文件 | 内容 |
|---|---|
| `notebook-lines.js` | 第一页批注 `NOTES`（轮数 / 时长 / 摸头 × 各档 × 3 句）、落款 `SIGNS`（各种情况） |
| `notebook-friends.js` | 她写给别人的 `GREET` / `MSG` / `DATA_MSG`、她的回复、`STICKER`、`CAMEO` |
| `pet-talk.js` | 拿数字说话 `DATA` / `DATA_REPLY`、互相接话 `REACT` / `REACT_BACK`；群聊沿用原角色 |
| `pair-chat.js` | `SKIN_PAIRS`：圣女、降智龙崽已有，查漏补齐；Claude 卫衣、魔术师和其余六个原角色各补一整套（三档） |

和她搭话的另一方，口吻要接得住她的皮肤（比如对着降智龙崽说话会放慢、哄着），所以对方的那几句在 `SKIN_PAIRS` 里一起换。

## 口吻

- **降智龙崽**：慢半拍、呆、省略号多、偶尔「嗷」，对数字没概念（「额度？……能吃吗」）。
- **Claude 卫衣**：觉得穿上就变聪明，假装是 Claude，用很笨的方式炫耀；骨子里还是爱吃饭的 DeepSeek。
- **圣女**：守规矩、恭敬、温柔，讲「合乎规矩」「准许了」。
- **魔术师**（她还没有日常台词，口吻是 Claude 的提议，loki 可以改）：机灵、好奇、袖子里藏着小秘密，说话带点小把戏（「猜猜在哪只手里？」「数字也能变出来喵」），保留原版的猫口癖。

## 验收

- 测试：四套皮肤每张表都有自己的条目；穿皮肤时挑到的是皮肤的，换回原皮挑到原版的；三套换衣服皮肤挑到的是原版 DeepSeek 的。
- 重跑 `tools/build-notebook-fonts.py`，新字都收进字体。
- 在预览里看四套各自的本子第一页、第二页。

## 留给写的人

各档句数照原版的量；具体每句怎么写由写的人按上面的口吻定，写完交 loki 过目。
