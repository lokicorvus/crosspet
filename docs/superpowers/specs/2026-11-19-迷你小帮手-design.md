# 迷你小帮手（好感度礼物）· 设计草稿

状态：**已被 [2026-11-20-迷你小帮手-互送-design.md](2026-11-20-迷你小帮手-互送-design.md) 接替**（素材部分仍然有效）。原来的状态：草稿，先给 Claude 试画一张（art/任务/2026-11-19-迷你小帮手-试画），画风和大小定了再往下做。

## 想做什么

好感度高了以后，朋友之间互送一只自己的迷你小帮手（像「派小帮手」delegating 那张图里的小人），陪在桌宠脚边。

## 素材：每个角色一张 4 宫格

- 一次生成一张方图（≥1024），2×2 四个姿态：待机、开心（跳）、睡觉、走路（朝右）。
- 程序按透明区域切成 4 张小图，缩到显示大小的两倍左右存（显示约 50–60 像素，存约 120 像素，同 tools/cards.py 的思路，免得 Windows 100% 缩放下糊）。
- 第三张（mini_work，art/规则/迷你-动作3.txt）：思考 2 帧（时间最长，轮播）、记笔记、抱书跑（干活）、抬手指你（等批准 / 问你）、鞠躬递礼物（刚收到时一次）。动作到这三张为止，打哈欠、摔跤之类暂时不要（2026-11-19 loki）。
- 皮肤也要有自己的迷你（2026-11-19 loki 改主意：反正一张图里全有，画起来不多）。做法：拿原角色定好的三张当底图只换衣服，所以等 Claude 三张都定了再画。现有皮肤：claude-saint、deepseek-hoodie / winter / pajamas / knit、gemini-magician、gpt-onesie（彩蛋角色不做）。
  - 要改 tools/art.py：皮肤的 mini 底图找不到自己的时，退回「基于」那个角色本批画好的 mini（现在会变成没有底图、从头画）。art.py 有 loki 没提交的改动，动之前先问。
- 规格：art/姿态/mini.md、art/规则/迷你.txt。机检的全身立绘规则不适用，人工验收。
- 第二张（mini_more，art/规则/迷你-动作2.txt）：横图 3×2，上排朝右跑 3 帧（轮播成跑步），下排挥手、坐着看书、抱书着急；拿第一张当底图，保证同一个小人。2026-11-19 预览定了绕圈跑、显示 100 像素高。
- 待定：迷你本人（Claude 那样），还是她的吉祥物（GPT 的小白龙、DeepSeek 的小鲸鱼、GLM 的小黑狐狸，delegating 图里已经这么画了）。

## 动作：全部交给代码

- 平时：待机图轻轻上下浮动，偶尔左右走两步（走路图 + 水平翻转 + 平移）。
- 跟着主桌宠：她开心 / 庆祝时小家伙跳一下（开心图）；她睡着了换睡觉图，配现有的 zzz 特效；她干活时在旁边晃。
- 特效（爱心、音符、汗滴）用 effects.js 现有的。
- 点它：跳一下，气泡说一句「是 X 送的」。

## 送和陪

- 到「好朋友」（或「挚友」，待定）时，朋友送一只自己的；小本子第二页记一笔「收到了 X 的小 X」。
- 一次只陪一只，每天轮换（收到过的里面挑）。
- 送它的那个朋友本人也站在桌面上时收起来，不重复。
- 设置里可以关掉。

## 放在哪

- 桌宠画布 580×560，人物 374×420 居中（effects.js 的 CW / AW），脚边两侧各有约 103 像素留白：50–60 像素的小帮手不用改窗口大小。
- 要确认：贴边探头时藏起来；鼠标穿透 / 「让开」时一起半透明；多桌宠时每只各自的。
