# 她的小本子 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 右键她 →「我们的小本子」，在她旁边弹出按角色主题画的相处记录面板（相处 / 干活 / 互动 / 最好的朋友 / 小成就），数据从装 CrossPet 那天算起，以前的干活记录从 AI 程序的本机记录补算。

**Architecture:** 记账全在主桌宠页面：纯函数 `notebook.js`（记一轮、按分钟累计、计数、小成就、出面板数据、合并备份）+ `notebook-backfill.js`（把外壳交来的精简事件拼成「轮」）。外壳只做三件事：读 AI 记录文件抽出精简事件、存 `notebook.json` 备份、开一个无边框小窗放 `notebook.html`（主题样式来自原型 `build/notebook-preview.html`）。Mac 先做完能实际看，Windows 跟上。

**Tech Stack:** 原生 JS（`node --test`、vm 页面测试）、Swift/AppKit/WKWebView、C#/WinForms/WebView2、Python fontTools（只在开发机上子集化字体）。

**Spec:** `docs/superpowers/specs/2026-11-08-notebook-design.md`；视觉定稿 `build/notebook-preview.html`（不入库，Task 4 把它搬进 `app/web`）。

## Global Constraints

- 只记数字和日期，不记对话内容，只存本机；补算只读时间戳和模型名。
- 起点 = 装 CrossPet 那天（数据目录建立时间）；装之前的轮数不计入，只进 `before`（「认识你之前，你已经和她干了 N 轮」）。
- 存 `localStorage['crosspet-notebook']`，外壳在数据目录另存 `notebook.json`，坏了 / 丢了互相恢复（同 `friendship.json`）。
- 只有主桌宠页面（`role === 'main'`）记账；额外那只的摸头 / 戳 / 生气经外壳转给主桌宠（同 `patted`）。
- 七张面板头部同高、内容顺序一样；角色字体只用于标题、分隔标题、批注、落款；正文和数字用系统字体。
- 不认识的角色用 Claude 的手册主题。
- 不手画动物、人物；面板里只用几何类插画（原型里已有的那些）。
- 换衣服统计不做（原型里没有这一栏，YAGNI）；Task 8 把设计文档改成一致。
- git：在 `notebook` 分支上做（从 `dev` 开，worktree 放 `~/Projects/crosspet-notebook`，主 worktree 有美术对话的改动不能碰）；只 `git add` 自己改的文件，禁止 `git add -A`；测试单独跑、看退出码再提交；提交署名行 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`；不推送、不合并。
- 测试命令：`node --test tests/*.test.js`、`for t in tests/*_test.cjs; do node $t; done`、`~/.dotnet/dotnet run --project tests/windows/LogicTests -c Release`。

## Review Focus

1. **页面重载 / 外壳重发状态文件**：同一个 Stop 事件被送来两次不能算两轮 → Task 3 用每个角色的 `lastTs` 去重，测试 `reload_does_not_double_count`。
2. **补算和实时记录重叠**：新版装上后实时记的轮，补算时又在记录文件里读到 → 只补 `end < store.liveSince` 的，测试 `backfill_skips_rounds_after_liveSince`。
3. **两边的备份不一致**（清了浏览器存储、换了数据文件夹）：合并时每个角色取「多的那份」，绝不把数往回拉 → Task 1 `merge_keeps_bigger_record`。
4. **AI 记录文件很大 / 有坏行 / 没有这个文件夹**：抽事件逐行读、坏行跳过、文件夹不存在就是空 → Task 5/7 用带坏行的夹具测。
5. **跨午夜 / 时区**：「最忙的一天」「凌晨」按本机时间算 → Task 1 用 `new Date(y, m, d, h)` 构造本地时间测。
