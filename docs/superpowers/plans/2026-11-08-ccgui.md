# CC GUI 接入

目标：在 Windows / macOS 的「接入 AI」中新增 CC GUI，一次接入后跟随宿主支持的任意 CLI。

方案：使用官方插件 SDK 的 onTurnStarted、onRuntimeEvent、afterTurn、onClosed。仅转发事件名、工具名、模型和会话标识，复用 crosspet-hook.py 的角色选择、动画、轮次门禁和多桌宠状态。Windows 通过系统 PowerShell 调用 CrossPet 自带 Python；macOS 使用 python3。首次接入 / 更新需要重开 CC GUI 加载插件。撤销移除本桥的启用记录，不改其他插件。
