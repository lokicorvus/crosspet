# Gemini 额度显示模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 设置里给 Antigravity 的 Gemini 额度加「显示哪些」：5小时和本周（默认，和 GPT / Claude 的额度一样）/ 5小时和 Claude/GPT（现在的样子）。

**Architecture:** 外壳照旧交 `{text, low, bars}`；网页留原始的一份，按模式用纯函数 `AgyQuota.view` 算出显示用的那份再存进 `quota.gemini`，换模式时重算。外壳只存设置、交给网页（照 `minisFrom` 的路子）。

**Tech Stack:** 纯 JS（浏览器 + Node 测试）、Swift（macOS 外壳）、C#（Windows 外壳）。

**Spec:** `docs/superpowers/specs/2026-11-24-gemini-额度显示模式-design.md`

## Global Constraints

- 设置键 `agyQuotaMode`，值 `"week"`（默认，任何别的值都按它）/ `"cg"`。
- 设置页文案：行名「显示哪些」，按钮 `data-v="week"`「5小时和本周」、`data-v="cg"`「5小时和 Claude/GPT」；放在「显示 Gemini 额度」那行下面，`agyQuota === false` 时藏起来。
- 默认模式的 text 和 `app/web/codex-quota.js` 的 `view` 同一格式：`<窗口> 剩余 N%`，用「 ｜ 」连，只在剩得最少（同样少取第一个）且有重置时间的那个后面加 ` · HH:mm 重置`（24 小时内，小时补零）或 ` · M/D 重置`；过了重置时间的写「剩余 100%」且不算最少。
- 只用 `group === 'Gemini'` 的 bars；label 去掉开头的「Gemini 」。没有 bars、或没有 Gemini 组：原样返回。`cg` 模式原样返回。
- 不改 Mac / Windows 的额度解析（`App+Quota.swift`、`AntigravityQuota.Parse.cs`）。

## Review Focus

1. 窗口刚好过了重置时间、外壳还没送新数据：该显示 100%，low 不该因为它为真 → Task 1 `past_reset_window_counts_full`。
2. 只有一个 Gemini 窗口（免费账号可能只有本周）：一行，label「本周」，不报错 → Task 1 `single_window`。
3. 外壳交 `null`（Antigravity 没开）：`quota.gemini` 为 null，换模式也不报错 → Task 2 `agy_mode_null_quota`。
4. 先换模式、后来额度：用的是当前模式 → Task 2 `agy_mode_before_quota`。
5. 额外那只桌宠（多桌宠）也是 Gemini：同样按模式显示 → Task 4/5 外壳把 `setAgyQuotaMode` 也发给 companions（照 `minisFrom` 在 companion case 列表和 companionLookJS 里加）。

- [ ] **Step 1: 写失败的测试**（`node:test`；样本用 Argon 合并后的四个 bars：Gemini 5小时 left .89 reset now+3600、Gemini 本周 .95 reset now+3·86400、Claude/GPT 5小时 1、Claude/GPT 本周 1）

```js
test('week_keeps_gemini_windows_like_gpt', () => {
  const v = view(q, 'week', now)
  assert.deepEqual(v.bars.map(b => b.label), ['5小时', '本周'])
  assert.match(v.text, /^5小时 剩余 89% · \d\d:\d\d 重置 ｜ 本周 剩余 95%$/)
  assert.equal(v.low, false)
})
test('cg_returns_original', () => assert.equal(view(q, 'cg', now), q))
test('unknown_mode_is_week', () => assert.deepEqual(view(q, 'x', now), view(q, 'week', now)))
test('no_bars_or_no_gemini_group_unchanged', () => { /* {text:'Gemini 剩余 50%'} 和 只有 Claude/GPT 组 的 q：view 返回同一个对象 */ })
test('null_passes_through', () => assert.equal(view(null, 'week', now), null))
test('weekly_tightest_gets_reset_mark_and_low', () => { /* 本周 left .08 reset now+3·86400：text 结尾「本周 剩余 8% · M/D 重置」，5小时那段没有「重置」，low true */ })
test('past_reset_window_counts_full', () => { /* 5小时 left .02 reset now-10：text 里「5小时 剩余 100%」，low 看本周 */ })
test('single_window', () => { /* 只有 Gemini 本周：bars 一项 label「本周」 */ })
```
