# 迷你小帮手：好友互送、围在身边 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 桌宠身边陪着一组迷你小帮手：她自己的 + 升到「好朋友」的 AI 互送的（最多 6 个），设置可关；GPT 飞、DeepSeek 游、Gemini / GLM 扑跳，其他人跑。

**Architecture:** 素材是每个角色一张横条 `characters/<id>/mini.webp`（外壳当「姿态 mini」扫进清单）。网页 `app/web/mini-helper.js` 出纯函数（crew：该显示谁；spotsFor / busyRoles：站位和分工）和一组 CSS 动画的小人；`index.html` 按好感度记录算 crew、演送礼。送礼记录 = 好感度 level ≥ 2（不另存），只加一个 `giftShown` 记演没演过；开关 `showMinis` 走外壳设置，和「不睡觉」一样。

**Tech Stack:** 原生 JS（网页，node:test 测纯函数，tests/*.cjs 跑页面脚本）、Swift（macOS 外壳）、C#（Windows 外壳，.NET 4.8）、Python + Pillow（切图拼图工具）。

**Spec:** `docs/superpowers/specs/2026-11-20-迷你小帮手-互送-design.md`

## Global Constraints

- 开关 `showMinis`，默认 true；关了一个都不显示。
- 最多 6 个：她自己的 + 最多 5 个好友；好友超过 5 个按「今天日期 + 她的 id」每天轮换，同一天不变。
- 好友 = 好感度记录里这一对 `Friendship.level(points) >= 2`；分数只涨不跌，送了不会没。好感度功能（friendshipOn）关着也照样显示已收到的。
- 送礼演过记在好感度那一对的记录上：`giftShown: true`。
- 送的小帮手穿送礼那位现在穿的衣服（清单里她的 poses.mini）。
- 移动方式按原版 id：gpt → fly，deepseek → swim，gemini、glm → pounce，其他 run。
- 小帮手站着 43 像素（画布 #stage 250×241），任何时候都不能出画布（离中线 |x| ≤ 104）；只在她脚边和身后，不挡脸、手、气泡、额度栏。
- 绕圈、换帧只用 CSS 动画；同一时刻待机时最多 1 个在绕圈，干活时最多 3 个。
- 贴边全部藏起来；彩蛋角色没有小帮手。
- 拼图每格 136×148，FRAMES 顺序三处一致：`tools/mini_sheet.py`、`tools/mini_cut.py`（引用前者）、`app/web/mini-helper.js`。
- `tools/art.py` 有 loki 没提交的改动，不许改；迷你出题全走 `tools/mini_art.py`。
- Windows 立绘只能从 `characters/<id>/<文件>` 读（不能有子目录）。
- 提交只暂存自己改的文件；提交说明结尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。不推送。

## Review Focus

1. **好友正穿着没有小帮手的皮肤**（比如 GPT 穿连体衣，连体衣还没画）：她送的小帮手应该还在，退回原版那套 → Task 1 的 `crew_falls_back_to_base_sheet_when_skin_has_none`。
2. **好感度记录里有已经不在清单里的角色**（用户删了自己做的角色、或彩蛋 id）：跳过，不出空格子、不报错 → Task 1 的 `crew_skips_unknown_and_egg_characters`。
3. **过了午夜**：轮换要换一批，而且不用重启 → Task 5 的 `crew_recomputed_every_minute`（假时钟跨过 0 点后 crew 变了）。
4. **送礼演到一半关了开关 / 换了角色**：不能残留礼物小人 → Task 5 的 `gift_cancelled_when_turned_off`。
5. **演彩蛋、贴边时**：整组收起，结束后原样回来 → Task 5 的 `crew_hidden_during_egg_and_tuck`。
