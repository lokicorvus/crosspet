# 自定义角色

角色都在 `~/Library/Application Support/CrossPet/characters/` 里（右键桌宠 →「设置…」→「文件夹」里的「角色」）。每个角色一个文件夹：

```
characters/
└── claude/
    ├── character.json     名字、台词、绑定哪个 App
    ├── idle.webp          平时（必须有）
    ├── idle-2.webp        同一姿态的第二张，停留久了会轮换
    ├── idle-blink.webp    眨眼帧（只有眼睛闭上，其他和 idle 完全一样）
    ├── portrait.webp      换角色窗口的大立绘和衣服卡用的展示图（可选，不放就用 idle；不是姿态，桌宠本身不用它；建议 512×768）
    ├── portrait-card.webp 衣服卡用的小图（可选，建议 256×384；不放就用 portrait，大图缩得太小在 Windows 上会糊）
    ├── avatar.webp        换角色窗口里角色卡的探头头像（可选，方形，从左下角探出脑袋；不放就用 portrait / idle；建议 192×192）
    ├── thinking.webp
    └── ……
```

改完右键 →「重新载入」即可生效，不用重启。

> 内置角色每次启动会从 App 里重新同步，直接改它们会被覆盖。想改内置角色，最简单的办法是**复制一份换个文件夹名**再改，比如 `claude-mine/`，并在新角色的 `character.json` 里把 `apps` 也写上，它就会顶替原来的角色出现（切到那个 App 时换成她）。想让她也来演那个 AI 干活的动作，再加上 [`reactTo`](#让自定义角色也来演其他-ai-的动作)。也可以在源码仓库的 `characters/` 里改好，重新编译安装。

## 改名

右键桌宠 →「设置…」，在「名字」里改，留空恢复默认。名字存在本机设置里，升级不会丢。

## character.json

```json
{
  "name": "Claude",
  "accent": "#e8a33d",
  "apps": ["com.anthropic.claudefordesktop"],
  "greeting": "我在这儿～",
  "lines": {
    "idle": ["在呢", "有什么要做的吗？"],
    "thinking": ["让我想想…"],
    "happy": ["搞定啦～"]
  }
}
```

| 字段 | 含义 |
|---|---|
| `name` | 默认名字（名牌上显示） |
| `accent` | 气泡边框颜色 |
| `apps` | 切到这些 App 时自动换成这个角色。填 App 的「程序标识」，查法：`osascript -e 'id of app "应用名"'` |
| `reactTo` | 她在场时，这些 AI 干活的动作也由她来演：写 AI 的角色 id 列表，如 `["claude", "gpt"]`，或 `"*"` 代表所有。不写就和原来一样。见下面的[让自定义角色也来演其他 AI 的动作](#让自定义角色也来演其他-ai-的动作) |
| `greeting` | 换成这个角色时说的第一句话 |
| `lines` | 每个姿态的台词，随机挑一句；没写的姿态不说话 |
| `glyph` | 读文件时身边飘的字符颜色，如 `{"fill": "#3b6fd8"}`；浅色字可以加 `"stroke"` 描边 |
| `idleActions` | 闲着时的专属小动作（姿态名列表），**有对应立绘才会用**，会和内置的哼歌 / 伸懒腰混着出现 |
| `pokePose` | 被戳时用的专属姿态，默认 `surprised` |
| `correctedPose` | 她刚出错或被打断后三分钟内你又发消息（多半是在纠正她）时用的姿态，内置的 Claude 用它说「You're absolutely right!」 |
| `longThink` | 想得久了换成专属姿态，如 `{"after": 20, "pose": "deepthink"}`（秒） |
| `fx` | 把某个姿态的身边特效换成 `effects.js` 里的具名特效，如 `{"thinking": "bubbles"}`。现有：`bubbles`（深海泡泡）、`steam`（热气）、`celebrate`（彩纸 + 闪光）、`victory`（只有金色闪光，立绘里自己画了皇冠时给 `proud` 用）、`priceDown` / `priceUp`（晃来晃去的价签，打折 / 涨价） |

专属姿态的名字可以自己起（比如 DeepSeek 的 `eat`、`slack`），只要立绘文件名对上、`lines` 里写上台词就行。内置的 DeepSeek 配置就是一个完整的例子。

角色文件夹名就是角色 id，各个 AI 接入写状态时用的就是它（`/tmp/crosspet/<id>-state.json`）。

## 让自定义角色也来演其他 AI 的动作

默认每个 AI 对应一个角色：Claude Code 干活是 Claude 在演，Codex 干活是 GPT 在演。想让**你自己的角色**陪你用所有 AI，在她的 `character.json` 里写 `reactTo`：

```json
{
  "name": "我的角色",
  "reactTo": ["claude", "gpt"]
}
```

- 值是 AI 对应的**角色 id**（`claude`、`gpt`、`deepseek`、`gemini`……），也可以写 `"*"` 代表所有 AI。不写就和原来一样，各演各的
- 她在场时，这些 AI 的**工作状态、多个对话同时干活、额度刷新 / 充值的庆祝**也由她来演；多个对话同时干活时，和原来一样按“多会话”合并显示，每个对话一张卡片
- **内置角色不受影响**：切到 Claude 的窗口，Claude 角色照样出现、照样演自己的
- 她自己没有的姿态，退回 `idle`（和别的角色一样），所以至少把常用姿态画上
- 额度小窗会列出她响应的那几家（前面标名字）；在「设置… → 额度」里打开「合并显示各家额度」则列出所有家
- 她「累了」的姿态只看她**自己**的额度，不看这些 AI 的

**只在她是当前角色时生效，不会自己切出去。** 想让她一直在场，需要关掉自动换角色：「设置…」里的「跟随前台应用」（Windows 上还有「跟随 AI 工作事件」）。关掉之后，切到别的 AI 的窗口不会再把她换走，想换角色时从右键菜单手动选；macOS 和 Windows 都会记住上次选的角色，重启后还是她。

> 内置角色每次启动会被重新同步，所以 `reactTo` 要写在**自己的角色**里（复制一份内置角色换个文件夹名，见上面）。

## 姿态

文件名 = 姿态名，可以带 `-2`、`-3` 表示同一姿态的多张图。缺哪个姿态就用 `idle` 顶上，只有 `idle` 也能跑。

| 姿态 | 什么时候出现 |
|---|---|
| `idle` | 平时 |
| `listening` | 收到你的消息 |
| `thinking` | 思考 |
| `reading` | 读文件、搜代码 |
| `writing` | 写文件、改代码 |
| `running` | 跑命令 |
| `searching` | 上网查资料 |
| `delegating` | 派子任务 |
| `drawing` | 画图 |
| `happy` | 一轮完成 |
| `proud` | 一轮里用了 8 次以上工具的大活完成 |
| `oops` | 出错 |
| `surprised` | 被打断 / 被戳 |
| `pat` | 被摸头 |
| `tired` | 额度快用完 |
| `compact` | 压缩上下文（没画时用 `writing` 顶上） |
| `asking` | AI 问你问题 / 等你授权，一直保持到你回答（目前支持 Claude Code 和 DeepSeek Harness；没画时用 `listening` 顶上） |
| `sleeping` | 10 分钟没动静 |
| `hum` / `stretch` / `yawn` | 闲着时偶尔哼歌、伸懒腰、打哈欠 |
| `idle-blink` | 眨眼帧 |
| `greet_morning` / `greet_noon` / `greet_afternoon` / `greet_evening` / `greet_night` / `greet_dawn` | 每个时段第一次见面时的登场动作：早上 5–11 点、中午 11–14、下午 14–18、晚上 18–23、深夜 23–2、凌晨 2–5 |
| `fest_halloween` / `fest_christmas` / `fest_newyear` / `fest_spring` / `fest_lantern` / `fest_dragonboat` / `fest_midautumn` / `fest_national` | 节日当天第一次见面时的节日装扮：万圣节、圣诞（12-24、25）、元旦、春节（初一到初七）、元宵、端午、中秋、国庆（10-1 到 7） |

登场动作的名字用**下划线**（`greet_morning`），不要用 `-`：`-` 表示同一姿态的多张图。台词写在 `lines` 里同名的键下（`"greet_morning": ["早上好"]`）。只写台词不画图也行，到时只说话不换动作；两样都没有就照常说 `greeting`。打过招呼的时段和节日记在本机，同一时段只打一次。

**Codex 重置提醒的台词**（只对 GPT 角色和它的皮肤有用，设置里打开「Codex 重置提醒」后才会说）：在 `lines` 里写 `resetAnnounced`（官方已宣布）、`resetDone`（宣布的重置已经到了）、`resetHigh`（预测 ≥70%）、`resetMid`（30–69%，或没给概率但预测等级高）、`resetLow`（更低）、`resetNone`（没有预测）、`resetQuiet`（没有预测也没有统计）、`resetOffline`（连不上那个网站）。台词里可以用 `{when}`（预计时间）、`{chance}`（概率）、`{window}`（「接下来 48 小时内」）、`{since}` / `{avg}`（上次重置是几天前、平均几天一次）。`resetMid` 至少留一句不带 `{chance}`，没给概率时只挑这种。没写的键用默认台词。专属动作 `reset_check` / `reset_bell` / `reset_hope` / `reset_maybe` / `reset_nope`（被问时查手机、官方已宣布、≥70%、30–69%、更低或没风声），没画的退回 `thinking` / `reset` / `happy` / `hum` / `sulk`；开发者控制台「场景演练」里的「Codex 重置提醒（6 档）」可以不联网挨个看效果。

彩蛋角色（`egg-*` 文件夹）用的是 `pop` / `pretend` / `caught` / `bye` 四张（可以多画一张 `escape`：没人点她、自己走掉时用，没画就用 `bye`），`character.json` 里多一个 `"egg": true` 和 `"host": "<出现在哪个角色那里>"`。名牌默认显示「<那个角色的名字>？」（假装是她）；写了 `"caption"` 就显示它（比如对手直接上门的 DeepSeek × GLM 彩蛋显示自己的名字）。

## 开发者控制台

**按住 ⌥ Option 再右键桌宠** →「开发者控制台…」，打开一个检查用的窗口（平时的右键菜单里不显示）：

- **姿态**：每个角色的每张立绘都列出来（缺图的标出现在用哪张顶上），点一下桌宠就演这一张并保持住，也可以一键轮播。
- **场景演练**：用和真实 AI 一样的事件流程跑一遍（一轮工作、大活戴皇冠、出错被纠正、压缩上下文、快速连发、额度紧张、GPT reset、DeepSeek 充值、彩蛋、摸头戳、睡着叫醒、闲置小动作、眨眼、切换角色），每个场景都写了预期效果。
- **实时事件**：真实 AI 发来的状态。测试时可以暂停，不让它们打断。
- **反馈**：每一项都能标「正常 / 有问题」并写备注，「保存反馈」会写到 `~/Library/Application Support/CrossPet/dev-feedback.md` 并复制到剪贴板，方便发给别人（或 AI）。

关掉控制台窗口，桌宠就恢复正常运行。

## 用 AI 画新立绘

1. 用 [角色生图提示词](prompts/角色生图提示词.md) 让 Codex（或其他能看参考图的生图 AI）画，**白底或透明底、全身、居中**。
2. 把画好的图放进源码仓库的 `characters/<角色id>/raw/`，文件名用姿态名（如 `thinking.png`）。
3. 运行：
   ```bash
   python3 tools/import.py <角色id>
   ```
   白底图和透明底 PNG 都会自动处理：白底抠掉背景，透明底直接用图自己的 alpha，统一大小并转成 WebP。有眨眼帧的话会自动对齐到 `idle`。
4. 重新编译安装（`./install.sh`），或者把生成的 `.webp` 直接拷进角色文件夹再「重新载入」。

单张处理：`python3 tools/prepare.py <图片> <角色id> <姿态名>`。

## 特效

每个姿态身边的小动画（小终端、浏览器卡片、画板、爱心……）在 `app/web/effects.js` 的 `surroundings(pose)` 里，用 SVG 画；可被角色点名的具名特效在同一文件的 `named` 里。

改完运行一次重叠检查，确认特效（包括会移动的路径）没有压到人物身上：

```bash
tools/fxcheck/run.sh        # 加参数 vis 会在 /tmp/crosspet-fxcheck 生成可视化图
```

加了角色或动作，想更新 README 的配图：`python3 tools/readme_images.py`（按 App 的真实布局把立绘、特效、气泡拼成图，输出到 `docs/images/`）。
