# 小本子用的字体

这里的字体文件是按小本子面板用到的字做的子集（`tools/build-notebook-fonts.py`），都以 SIL Open Font License 1.1 发布：
<https://openfontlicense.org/open-font-license-official-text/>

| 文件 | 字体 | 作者 / 来源 |
|---|---|---|
| notebook-kai.woff2 | 霞鹜文楷 LXGW WenKai 的子集，按 OFL 保留字体名的要求改名 Notebook Kai | LXGW，<https://github.com/lxgw/LxgwWenKai> |
| zcool-kuaile.woff2 | ZCOOL KuaiLe（站酷快乐体） | ZCOOL，<https://github.com/google/fonts/tree/main/ofl/zcoolkuaile> |
| zcool-xiaowei.woff2 | ZCOOL XiaoWei（站酷小薇体） | ZCOOL，<https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei> |
| zcool-qingke-huangyou.woff2 | ZCOOL QingKe HuangYou（站酷庆科黄油体） | ZCOOL，<https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou> |
| ma-shan-zheng.woff2 | Ma Shan Zheng（马善政毛笔楷书） | Ma ShanZheng，<https://github.com/google/fonts/tree/main/ofl/mashanzheng> |
| long-cang.woff2 | Long Cang（龙藏体） | Chen Xiaomin，<https://github.com/google/fonts/tree/main/ofl/longcang> |
| zhi-mang-xing.woff2 | Zhi Mang Xing（钟齐志莽行书） | Zhong Qi，<https://github.com/google/fonts/tree/main/ofl/zhimangxing> |

子集是 OFL 允许的修改版本。霞鹜文楷声明了保留字体名（霞鹜、霞鶩、落霞孤鹜、落霞孤鶩、LXGW），所以它的子集改名 Notebook Kai；其余六款没有保留字体名，沿用原名。
