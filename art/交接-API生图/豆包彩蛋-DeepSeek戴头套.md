# 豆包彩蛋：DeepSeek 偷戴豆包的头套冒充豆包

当前角色是豆包时偶尔出现：DeepSeek 把豆包的毛绒头套套在自己头上冒充豆包，蓝头发、鲸鳍耳朵和鲸鱼尾巴全露在外面。豆包本人不出场。

要画 5 张。提示词都已拼好，在 [art/任务/2026-11-23-彩蛋-DeepSeek戴豆包头套/提示词/](../任务/2026-11-23-彩蛋-DeepSeek戴豆包头套/提示词/)，打开对应文件，把「提示词」那一段整段复制即可。

## 通用要求

- 接口和参数照 [新角色与新皮肤.md](新角色与新皮肤.md) 第 0 节：透明背景、最高质量、`n = 1`，1024×1024。
- **每张单独调用**，附件都是同样 3 张，按这个顺序：
  1. `characters/deepseek/idle.webp`（DeepSeek 本人）
  2. `docs/prompts/ref-deepseek.webp`（DeepSeek 设定图）
  3. `characters/doubao/idle.webp`（豆包：只抄她的头套）
- 文件命名：`egg-doubao__<姿态>__v<N>.png`，第一次画是 v1，交回后放进 `art/任务/2026-11-23-彩蛋-DeepSeek戴豆包头套/成品/`。
- **先只画 `pop`**，作者看过、确认头套像、人也认得出是 DeepSeek，再画剩下 4 张。

## 清单

| # | 姿态 | 画面 |
|---|---|---|
| 1 | pop · 登场 | 戴着头套，张开双臂蹦出来「锵锵～」 |

| 5 | escape · 溜走 | 戴着头套、拿着饭团，朝画面右边蹦蹦跳跳溜走 |

## 自查

- 背景真透明，没有地板、投影、特效、字。
- 头套和豆包的一模一样：圆脸、棕色齐耳短发、小圆眼、小「o」嘴，表情永远不变。
- 一眼认得出是 DeepSeek：深蓝头发从头套下面漏出来，鲸鳍耳朵从两边戳出来，鲸鱼尾巴在画面右边，穿她自己的女仆装。没有豆包的紫青头发、马尾和衣服。
- 戴着头套时，头套顶不比 DeepSeek 平时呆毛的尖高；5 张人一样大。
- 道具都贴着手或身体，不悬空。
