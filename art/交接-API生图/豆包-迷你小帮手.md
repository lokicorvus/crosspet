# 豆包：迷你小帮手

好感度升到「好朋友」那天，豆包会送对方「一只小小的我」，陪在桌宠脚边。现在豆包还没有这只小帮手，要画 4 张。提示词都已拼好，在 [art/任务/2026-11-22-豆包-迷你小帮手/提示词/](../任务/2026-11-22-豆包-迷你小帮手/提示词/)，打开对应文件，把「提示词」那一段整段复制即可。

## 通用要求

- 接口和参数照 [新角色与新皮肤.md](新角色与新皮肤.md) 第 0 节：编辑接口、透明背景、最高质量、`n = 1`。**每张只画 1 版**，作者看过需要再说重画哪张。
- 尺寸：`mini` 是 1024×1024 方图；`mini_more`、`mini_work`、`mini_carry` 是 **1536×1024 横图**。
- **每张单独调用**，只附下表写的附件，按顺序传，第一张是底图。
- 文件命名：`doubao__<姿态>__v<N>.png`，第一次画是 v1，交回后放进 `art/任务/2026-11-22-豆包-迷你小帮手/成品/`。
- **必须按顺序画，每一步等作者选定再往下**：
  1. 先画 `mini`。
  2. 作者选定后，用选定的那版当底图，画 `mini_more` 和 `mini_work`。
  3. `mini_work` 选定后，再画 `mini_carry`。

## 豆包这只要注意的

- 小帮手是**她自己的 Q 版**（约 2 头身），不是那个豆包头套。底图 delegating 里飞出去的是两个小头套，那是大豆包派的帮手，不要照着画成头套。
- 头套缩小后夹在胳膊下，表情永远不变；不画星星。
- 比例按第 3 张画风参考（Claude 的小帮手）来，所有角色的小帮手要像一套。提示词里 PROPORTIONS、HEIGHT LOCK 两条写的是大立绘，小帮手不按它们。
- 只留 50 像素也认得出的特征：
  - 紫到青的卷发，马尾和两个圆环发饰在**她自己的左边**（正面时在画面右边）；
  - 白短上衣带圆环 logo，蓬袖带青色袖口；
  - 白裙子和两片短的紫到青衣摆；
  - 袜子左右不同：紫色在她的右腿，白色在左腿；
  - 白球鞋。
- 录音笔、挂绳、工牌、吊袜带太小看不清，不画。

### 自查

- 背景真透明，没有地板、投影、特效、字。
- 每格一个小人，彼此不碰、不碰边框，大小一致。
- `mini_more`、`mini_work`、`mini_carry` 里的小人和选定的 `mini` 是同一个：头一样大、发色和马尾的方向一致。
- `mini_carry` 三帧和 `mini_work` 左下那个抱书的一模一样，只有腿在动。
