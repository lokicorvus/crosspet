# 豆包：整套立绘

定妆图已经定了：`doubao__idle__v3.png`（2026-11-20）。整套 56 张都以它为参考，提示词都已拼好，整段复制即可。

## 通用要求

- 接口和参数照 [新角色与新皮肤.md](新角色与新皮肤.md) 第 0 节：编辑接口、透明背景、1024×1024、最高质量、`n = 1`。**每张只画 1 版**，作者看过需要再说重画哪张。
- **每张单独调用**，只附本节写的附件。不要附这套里其他画好的姿态（有底图的除外），否则偏差会一张张累积：脸越画越成熟、眼线越画越粗。
- 附件 `doubao__idle__v3.png` 就是定妆图，每张都附。有「底图」的几张，底图排第一个。
- 文件命名：`doubao__<姿态>__v<N>.png`，第一次画是 v1。
- **顺序有要求**：眨眼帧、各个 `_right`、各个 `_peek` 要拿前面画好的图当底图，先画底图那张、交给作者看过，再画它。
- **贴边四张**：切口不用正好压在边框上，导入时程序会自动裁；但必须是一条从身上直直切下去的竖线。
- portrait 是带完整背景的竖图：`background: "opaque"`、`size: "1024x1536"`。其他都是透明方图。

### 头套和星星

角色锁定里写清楚了：头套平时夹在胳膊下，动作里没提就不画；红温系列里她会把头套套到头上躲起来（sulk），被哄时掀起一点偷看（coaxed）；节日会给头套也打扮一下。星星只在动作里写到时出现。设定图上的「SEED」字样不画。

### 自查（除了通用的那几条）

- 和定妆图并排放：头一样大、腿一样短，没有越画越瘦高。
- 马尾在**她自己的左边**（正面时在画面右边），吊袜带和紫色袜子在她右腿；转身、贴边时跟着身体走，不跟着画面翻。
- 头套的脸永远是那个表情，不会变成第二个角色；没有飘在空中的东西；身上没有乱码的字。
