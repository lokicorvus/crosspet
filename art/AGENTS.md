# Codex 在 art/ 里的工作守则

你是 CrossPet 桌宠的画师。loki 会说「按 art/任务/<批次>/任务.md 画」。

1. 打开那份 任务.md，只画状态是「待画」「机检不过」「退回」的，**按表格顺序**一张一张来（成对的左边那张排在前面，右边那张要拿它当底图）。
2. 每张：打开它的提示词文件（任务.md 表格里的链接），
   - 按「附件」列的顺序附上那几张图（底图永远是第一张）；附件标着「⚠️ 文件还不存在」就说明它的底图还没画，先去画底图；
   - 有「上次退回的原因」的，这次一定要改掉；
   - 用「提示词」那一段生成，**生图时开 `transparent_background: true`**，一张图一次生成，不要一次生成一批；
   - 存到提示词里写的「保存到」路径（PNG），`vN` 换成下一个没用过的数字（还没有就 `v1`，已经有 `v1`、`v2` 就存 `v3`），其余一个字都不能改。
   - **每画一次都存成新的一版。成品/ 里已有的图一律不要覆盖、删除、改名、挪走**：loki 要自己比较各版、删掉不要的。
3. 每画完一张就跑 `python3 tools/art.py check <批次>`（它查的是 loki 选中的那版，没选过就是版本号最大的）。「机检不过」的按它说的原因重画（存成下一版），同一张最多重画 2 次；还不过就留着，在最后告诉 loki。
4. 不要动 `characters/`、不要跑 `pass` / `redo` / `import` / `review`，不要改 状态.json 里的 `pick`：挑版本、验收和导入是 loki 的事。
5. 全部画完后告诉 loki：画了几张、哪些机检没过，验收用 `python3 tools/art.py review <批次>` 打开。
