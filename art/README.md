# 立绘生产线

所有画图的事都在这个文件夹里：Codex 画好直接存进来，机器先检查一遍，loki 在对比页上看图验收，通过的再导入到 `characters/`。
旧的 `docs/prompts/` 留着当存档，新活都走这里。

```
art/
  README.md        就是这份
  AGENTS.md        Codex 的工作守则（Codex 在这个文件夹里干活时自动读）
  规则/*.txt       拼提示词用的英文段落：通用格式、多会话、贴边、探头、成对、点名
  角色/<id>.md     每个角色一份：角色锁定、参考图、每个姿态她自己的动作
  姿态/<姿态>.md   每个姿态一份：用途、拼哪几段规则、方向、成对 / 底图、导入参数、默认动作
  任务/<批次>/     一批活一个文件夹
    任务.md        清单和进度（工具生成，别手改）
    状态.json      工具记的状态
    提示词/        一张图一份，写好了保存路径和要附的附件
    成品/          Codex 画好存这里（不进 git）
    对比.html      看图验收的页面（不进 git）
  原图/<角色>/<姿态>/v1.png v2.png …   导入过的每一版原图（不进 git），想换回旧版就从这里拿
```

## 一批活怎么走

1. **出题**（我或 loki）：`python3 tools/art.py new <批次> <姿态...> [--chars 角色,角色]`
   不写 `--chars` 就是所有上线的角色。例：`python3 tools/art.py new 2026-11-集合举手 roll_call`
2. **画**（Codex）：跟它说「按 art/任务/<批次>/任务.md 画」。它照 [AGENTS.md](AGENTS.md) 一张一张画，存进 `成品/`，画完自己跑检查。
3. **验收**（loki）：打开 `art/任务/<批次>/对比.html`。每张新图旁边是现在用的那张、底图和待机图。
   - 满意：`python3 tools/art.py pass <批次> 角色:姿态`（或 `all`，所有机检过了的）
   - 不满意：`python3 tools/art.py redo <批次> 角色:姿态 "手太长了"`：原因写进那张的提示词，旧图挪到 `成品/退回/`，再让 Codex 画一次
4. **导入**：`python3 tools/art.py import <批次>`：通过的原图存进 `art/原图/`，处理成 `characters/<角色>/<姿态>.webp`。

随时看进度：`python3 tools/art.py status`。

## 机器检查查什么

- 透明背景（四个角、整体不能全不透明）
- 头顶不贴上边框（呆毛、帽子、角也要在画里）；普通姿态身体不碰左右边框、脚在底边附近
- 贴边 / 探头：切口在对的那一边，另一边不贴边
- 人物大小和待机图比（差一成以上提醒：桌面上会忽大忽小）
- 成对的后一张（比如 busy_right）：和先画的那张方向要相反（轮廓比对），也不能是直接镜像翻转

机检只拦明显的错，长相、手、细节还是要人看。

## 左右成对

忙碌、手忙脚乱、贴边都是左右两张。**先画左边，右边拿画好的左边当底图改**，不镜像翻转：单边的发饰、辫子、尾巴、异色瞳跟着她的身体走，不跟着画面翻。
探头在同一边的贴边图上改。这些在 `姿态/*.md` 的「底图」「成对」里写着，工具会自己排顺序、写附件。

## 加新东西

- **新姿态**：在 `姿态/` 加一份（照现有的写），要她们各自不同的动作就在 `角色/<id>.md` 的「动作」里加一行。
- **新角色 / 新皮肤**：在 `角色/` 加一份；皮肤写「基于: 原角色」，没写的动作用原角色的。
- **改规则**：改 `规则/*.txt`，下次出题就用上。已经出好的题要重新出（删掉那个批次文件夹再 new）。
